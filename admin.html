Вход для владельца

Покупатели видят только каталог. Изменять товары можно только с личным ключом доступа GitHub (токеном): без него эта страница ничего не делает.

Как получить токен (один раз, 2 минуты)
  1. Зайдите на GitHub → фото профиля → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories и выберите только репозиторий магазина.
  3. Permissions → Repository permissions → Contents: Read and write. Больше ничего не включайте.
  4. Срок действия поставьте 90 дней, нажмите Generate и скопируйте токен сюда. Токен хранится только в этой вкладке и пропадает при её закрытии.

Товаров пока нет. Нажмите «Добавить товар».
