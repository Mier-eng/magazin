# Дом и Мастерская: каталог товаров

Статический сайт-каталог для одного продавца: без сервера, без базы данных, без регистрации покупателей.
Покупатели только смотрят товары и пишут вам в WhatsApp. Менять товары можете только вы (через `admin.html`).

## 1. Один раз настроить `config.js`

Откройте `config.js` и впишите:
- `whatsappNumber`: ваш номер в международном формате, только цифры;
- `githubRepo`: `логин/репозиторий` (например `ivan/magazin`);
- `city` и `cityIn`: город в двух падежах (Сухум / Сухуме).

`siteUrl` оставьте пустым: пока сайт на github.io, адрес вычисляется из `githubRepo`.

## 2. Выложить на GitHub Pages

1. Создайте публичный репозиторий. Галочки «Add a README», «.gitignore», «license» **не ставьте**: все файлы уже есть в проекте.
2. Нажмите «uploading an existing file» и перетащите **содержимое** распакованной папки (не сам zip и не внешнюю папку). Нажмите Commit changes.
3. Settings → Pages → Source: Deploy from a branch → ветка `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты сайт откроется по адресу `https://логин.github.io/репозиторий/`.
5. Откройте `…/admin.html`, войдите и нажмите **«Обновить страницы сайта»** один раз, чтобы адреса в страницах товаров, карте сайта и robots.txt стали вашими.

## 3. Управление товарами (admin.html)

Адрес: `https://логин.github.io/репозиторий/admin.html`. На сайте ссылки на него нет, поисковики его не индексируют.

Для входа нужен токен GitHub (инструкция есть на самой странице):
Settings → Developer settings → Personal access tokens → **Fine-grained tokens**, доступ только к репозиторию магазина, право **Contents: Read and write**, срок 90 дней.

Что можно делать: добавлять товары с фото (фото сжимаются автоматически), менять цену и описание, отмечать «продано», удалять. Каждое действие сохраняется коммитом в репозиторий, сайт обновляется через 1–2 минуты.

Безопасность: без токена страница ничего не меняет, а токен хранится только в открытой вкладке и стирается при её закрытии. Никому не показывайте токен. Если он утёк, удалите его в настройках GitHub и создайте новый. Включите двухфакторную защиту на аккаунте GitHub.

## 4. Свой домен позже

1. Купите домен и в Settings → Pages → Custom domain впишите его, затем включите Enforce HTTPS (DNS-записи покажет GitHub).
2. В `config.js` впишите `siteUrl: 'https://ваш-домен'`.
3. В `admin.html` нажмите «Обновить страницы сайта».
4. Добавьте новый домен в Google Search Console и Яндекс.Вебмастер и отправьте `sitemap.xml`.

## Структура

```text
index.html, about.html, contacts.html   страницы сайта
admin.html                              управление товарами (только для владельца)
config.js                               настройки магазина
products.json                           список товаров (меняется через admin.html)
tovar/                                  страницы товаров (создаются автоматически)
images/                                 фото товаров
js/  css/                               скрипты и стили
sitemap.xml, robots.txt                 для поисковиков (создаются автоматически)
scripts/generate-pages.mjs              запасной вариант: пересоздать страницы на компьютере (нужен Node.js)
```
